# Reading 阅读 — 知识点结构

> Year 3 Reading：45 分钟，约 39 题，在线作答。阅读若干篇短文，每篇配 5–8 道选择题（偶有点选、排序题）。

---

## 一、必须认识的五种文体（Text Types）

NAPLAN 阅读的文章按文体出题，孩子要能一眼认出"这是什么类型的文章"，因为不同文体的出题套路不同。

### 1. Narrative 故事 / 记叙文
- **特征**：有人物（characters）、场景（setting）、情节（plot：开头 → 问题 → 解决）
- **常考**：人物感受、事件顺序、为什么人物这样做、故事教会我们什么
- **例子**：童话、小说节选、寓言

### 2. Information Report 信息说明文
- **特征**：介绍一类事物（动物、地方、事物），用事实（facts），常有标题、小标题、图表
- **常考**：找具体事实、小标题作用、图表信息、分类关系
- **例子**：介绍袋熊的文章、介绍火山的文章

### 3. Persuasive 议论文 / 说服文
- **特征**：作者有明确观点（opinion），用理由（reasons）说服读者
- **常考**：作者的观点是什么、作者用了什么理由、哪句是事实哪句是观点（fact vs opinion）
- **例子**："学校应该养宠物"、"孩子应该少看电视"

### 4. Procedure 步骤说明文
- **特征**：教你做一件事，有材料清单（materials）+ 编号步骤（steps），用祈使句（Cut... Mix... Fold...）
- **常考**：第几步做什么、为什么某步骤重要、需要什么材料
- **例子**：食谱、手工制作说明、游戏规则

### 5. Poetry 诗歌
- **特征**：分行（lines）、分节（stanzas）、可能押韵（rhyme）、用比喻和想象
- **常考**：押韵词、诗描写的是什么、某个词让你想到什么画面

## 二、五级阅读能力（题型分类）

### 能力1：字面理解（Literal comprehension）——"答案就写在文中"
- 题目样子：*What colour was the dog?* / *Where did Sam go first?*
- **策略**：回到原文找关键词，答案通常一字不差地在某一句里。
- 这是最基础的分，**必须全对**。

### 能力2：推断（Inference）——"答案藏在字里行间"
- 题目样子：*How was Mia feeling when she dropped the cake?* / *Why did Dad close the window?*
- **策略**：文中不会直说 "Mia was sad"，但会写 "Mia's eyes filled with tears" → 推断出 sad/upset。
- 教孩子口诀：**"文中的线索 + 我知道的常识 = 推断"**

### 能力3：主旨大意（Main idea / Purpose）
- 题目样子：*What is this text mainly about?* / *Why did the author write this text?*
- **策略**：看标题 + 第一段 + 最后一段；问自己"整篇文章在讲哪一件事"。
- 干扰项特点：只是文中"提到过的一个细节"，不是"整篇的主题"。
- 作者意图三选一：**to entertain（讲故事逗你开心）/ to inform（告诉你知识）/ to persuade（说服你）**

### 能力4：词义猜测（Vocabulary in context）
- 题目样子：*In this text, the word "enormous" means...*
- **策略**：把选项代回原句读一遍，看哪个通顺；用前后句的线索猜。

### 能力5：文章结构与写作手法（Text structure & language features）
- 题目样子：*Why is this sentence in bold?* / *What does the heading tell the reader?* / *Which word tells you the order of events?*
- **策略**：认识文本特征的作用——
  - 标题（heading）→ 告诉你这段讲什么
  - 加粗（bold）→ 强调重要词
  - 图片说明（caption）→ 解释图片
  - 时间连词（first, then, next, finally）→ 事件顺序

## 三、答题策略（考试技巧）

1. **先读题再读文？不。** Year 3 文章很短，先快速通读文章（1–2 分钟），再逐题回原文核对。
2. **每题都回原文验证**，不凭印象选。
3. **排除法**：先划掉明显错的两个选项，再在剩下两个里细比。
4. **不会的先选一个再标记**，NAPLAN 不倒扣分，**绝不留空**。
5. **注意 NOT / EXCEPT 题**：*Which of these is NOT...* —— 提醒孩子圈出 NOT。
6. 时间分配：39 题 45 分钟 ≈ 每篇文章连读带做 7 分钟。

## 四、日常训练方法

- **每天朗读 10 分钟**：读完让她用一句话概括"这段讲了什么"（练主旨）。
- **提问三连**：读完一篇问三个问题——一个字面（文中写了什么）、一个推断（她为什么这样做/心情如何）、一个观点（你觉得作者想告诉我们什么）。
- **推荐读物难度**：Year 2–4 桥梁书。如 Billie B Brown → Zac Power → Roald Dahl（*The Twits*, *Fantastic Mr Fox*）循序渐进。
- 非虚构：*National Geographic Kids*、DK Readers，练 information report 文体。
