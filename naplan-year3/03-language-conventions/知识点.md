# Conventions of Language 语言规范 — 知识点结构

> Year 3：45 分钟，约 40 题，在线作答。分两部分：**Grammar & Punctuation（语法与标点）** 和 **Spelling（拼写）**。拼写题在线上是"听音频输入单词"或"找出错词并改正"。

---

## 第一部分：Grammar 语法

### 1. 词类（Parts of Speech）—— 四大金刚

| 词类 | 作用 | 例子 | 记忆口诀 |
|------|------|------|---------|
| Noun 名词 | 人、地、物、事 | dog, school, Ruby, happiness | naming word |
| Verb 动词 | 动作、状态 | run, jump, is, have | doing word |
| Adjective 形容词 | 描写名词 | big, red, beautiful | describing word |
| Adverb 副词 | 描写动词（怎样做） | quickly, softly, yesterday | 常以 -ly 结尾 |

**常考题型**：*Which word in this sentence is a verb?* / *Choose the adjective that best completes the sentence.*

- **专有名词（proper nouns）要大写**：人名（Chloe）、地名（Melbourne）、月份（March）、星期（Monday）、节日（Christmas）。
- **代词（pronouns）**：he, she, it, they, we, him, her, them。常考：选对代词——*Tom lost ___ hat.* → **his**。

### 2. 动词时态（Tense）

| 时态 | 形式 | 例子 |
|------|------|------|
| 现在 | play / plays | She **plays** netball. |
| 过去 | played | Yesterday she **played** netball. |
| 将来 | will play | Tomorrow she **will play** netball. |
| 进行 | is/was playing | She **is playing** now. |

**必背不规则过去式**（Year 3 高频考点）：
- go → **went**, come → **came**, see → **saw**, run → **ran**
- eat → **ate**, take → **took**, give → **gave**, make → **made**
- say → **said**, tell → **told**, buy → **bought**, bring → **brought**
- catch → **caught**, teach → **taught**, think → **thought**
- fly → **flew**, draw → **drew**, know → **knew**, grow → **grew**
- swim → **swam**, sing → **sang**, drink → **drank**, ring → **rang**
- write → **wrote**, ride → **rode**, break → **broke**, speak → **spoke**

**常考题型**：*Yesterday we ___ to the beach.* → A) go B) goes C) went D) going

### 3. 主谓一致（Subject–Verb Agreement）

- 单数主语 + 动词加 s：*The dog **barks**.*
- 复数主语 + 动词原形：*The dogs **bark**.*
- is/are, was/were, has/have 的选择：
  - *The children **were** (not was) playing.*
  - *There **are** (not is) three birds.*

### 4. 连词（Conjunctions）

| 连词 | 意思 | 例子 |
|------|------|------|
| and | 并且 | I like apples **and** bananas. |
| but | 但是 | I ran fast **but** missed the bus. |
| or | 或者 | Do you want tea **or** juice? |
| because | 因为 | She smiled **because** she won. |
| so | 所以 | It rained, **so** we stayed inside. |
| when | 当…时 | Wash your hands **when** you finish. |
| if | 如果 | **If** it rains, we will stay home. |

**常考题型**：*I wore my coat ___ it was cold.* → because

### 5. 句子结构（Sentences）

- **完整句子**必须有主语和动词：*The dog barked.* ✓ / *Running in the park.* ✗（不是完整句）
- **句子类型**：
  - Statement 陈述句：*The cake is ready.*
  - Question 疑问句：*Is the cake ready?*
  - Command 祈使句：*Eat your cake.*
  - Exclamation 感叹句：*What a delicious cake!*
- **常考**：哪一个是完整句子？两个短句怎么合成一个（用连词）？

### 6. 冠词与介词

- **a / an**：辅音音开头用 a（a dog, a university），元音音开头用 an（an apple, an hour）。
- **常考介词**：in, on, under, behind, between, at, to。*The cat is ___ the table.*

## 第二部分：Punctuation 标点

### 1. 大写字母（Capital Letters）——最常考！
- 句子开头
- 人名、地名、月份、星期、节日
- 单独的 "I"（*My friend and **I** went home.*）
- 书名/标题的主要单词

### 2. 句末标点
- 句号 full stop（.）→ 陈述句、祈使句
- 问号 question mark（?）→ 疑问句
- 感叹号 exclamation mark（!）→ 强烈情感

### 3. 逗号（Commas）
- **列举**：*I bought apples, bananas and oranges.*（注意：澳洲惯例 and 前一般不加逗号）
- 句首状语后：*After lunch, we played outside.*

### 4. 撇号（Apostrophes）—— Year 3 重点考

**用法1：缩写（contraction）—— 代替省略的字母**
| 完整 | 缩写 |
|------|------|
| do not | don't |
| can not | can't |
| it is | it's |
| I am | I'm |
| they are | they're |
| we will | we'll |
| she has | she's |

**用法2：所有格（possession）—— 表示"谁的"**
- *the girl**'s** hat*（一个女孩的帽子）
- 注意陷阱：**its**（它的，无撇号）vs **it's**（it is 的缩写）
- 复数不是加撇号！*two dog~~'s~~* ✗ → *two dogs* ✓（NAPLAN 大爱这个陷阱）

### 5. 引号（Speech Marks / Quotation Marks）
- 直接引语加引号：*"Come here," said Mum.*
- 常考：哪句话的引号位置正确？说话内容和 said 之间用逗号。

## 第三部分：Spelling 拼写

### 1. 必会拼写规则

| 规则 | 说明 | 例子 |
|------|------|------|
| 复数 +s / +es | s, x, ch, sh 结尾加 es | box→boxes, brush→brushes |
| y 变 i 加 es | 辅音+y 结尾 | baby→babies, story→stories |
| f 变 v 加 es | | leaf→leaves, wolf→wolves |
| 双写加 ing/ed | 短元音+单辅音结尾 | run→running, stop→stopped |
| 去 e 加 ing | | make→making, ride→riding |
| y 变 i 加 ed | | cry→cried, carry→carried |
| ck 规则 | 短元音后用 ck | duck, black, clock |
| 长元音拼法 | ai/ay, ee/ea, oa/ow, igh | rain, play, seen, boat, night |

### 2. 高频易错词（Year 3 拼写测试常客）

**必须全对的基础词：**
because, friend, school, people, said, they, was, were, when, where, which, there, their, again, always, before, thought, brought, caught

**同音词陷阱（homophones）——语法拼写都爱考：**
| 组 | 区别 |
|---|------|
| there / their / they're | 那里 / 他们的 / they are |
| to / too / two | 到 / 也·太 / 二 |
| your / you're | 你的 / you are |
| its / it's | 它的 / it is |
| hear / here | 听 / 这里 |
| where / wear | 哪里 / 穿 |
| know / no | 知道 / 不 |
| right / write | 对 / 写 |

### 3. 拼写题型（在线考试形式）
1. **听写式**：音频读一个词和例句，孩子输入拼写。→ 平时练习：家长报词听写。
2. **找错改错式**：*The dog chaced the ball.* 找出错词并写出正确拼写（chased）。

### 每周听写建议
每周 10 个词（8 个规则词 + 2 个易错词），周一学、周三复习、周五测。错词进错题本，下周再考一次。
