## Part 1 — Grammar 语法（15题）

**Q3.** Choose the correct word: *Yesterday we ___ to the museum.*

**Q4.** Choose the correct word: *Sam ___ his lunch every day at noon.*

**Q7.** Choose the correct word: *I wanted to go to the party, ___ I was too sick.*

**Q8.** Which is a complete sentence?

## Part 2 — Punctuation 标点（10题）

**Q16.** Which sentence is written correctly?
- A) my dog is called max.
- B) My dog is called max.
- C) My Dog is called Max.
- D) My dog is called Max.

**Q17.** Which sentence needs a **question mark**?
- A) What time does the movie start
- B) The movie starts at two o'clock
- C) I love going to the movies
- D) Buy your ticket at the door

**Q18.** Which sentence is punctuated correctly?
- A) I bought apples bananas and grapes.
- B) I bought apples, bananas and grapes.
- C) I bought, apples bananas, and grapes.
- D) I bought apples bananas, and, grapes.

**Q19.** Which word is the short way of writing **do not**?
- A) dont
- B) do'nt
- C) don't
- D) don t

**Q20.** Choose the correct word: *___ raining outside, so take your coat.*
- A) Its
- B) It's
- C) Its'

**Q21.** Which sentence uses the apostrophe correctly?
- A) The boys' hat blew away. (one boy)
- B) The boy's hat blew away. (one boy)
- C) The boys hat blew away. (one boy)
- D) The boy hat's blew away. (one boy)

**Q22.** Which sentence is written correctly?
- A) "Come inside now, said Mum."

**Q23.** Which sentence is written correctly?

**Q25.** Which sentence should end with an **exclamation mark**?

## 答案与解析

### Part 1 — Grammar
| 题号 | 答案 | 解析 |
|---|---|---|
| Q1 | C | jumped 是动作（doing word）。 |
| Q2 | A | hungry 描写 possum（名词）→ 形容词。quickly 是副词，注意区分。 |
| Q3 | C | Yesterday → 过去式，go 的不规则过去式是 went。 |
| Q4 | B | every day + 单数主语 Sam → eats。 |
| Q5 | C | children 是复数 → were。 |
| Q6 | C | 因果关系 → because。 |
| Q7 | A | 转折 → but。 |
| Q8 | C | 只有 C 有主语（My sister）+ 动词（sings）。 |
| Q9 | C | 名词前用形容词性物主代词 her。 |
| Q10 | B | orange 元音开头 → an。 |
| Q11 | C | draw 的不规则过去式 drew（drawed 是典型错误）。 |
| Q12 | C | slowly 描写 moved（怎样移动）→ 副词。 |
| Q13 | B | four cupcakes 复数 → are。 |
| Q14 | C | 做主语用 I，且习惯上把自己放后面：Jack and I。 |
| Q15 | A | 飞越树 → over。 |

### Part 2 — Punctuation
| 题号 | 答案 | 解析 |
|---|---|---|
| Q16 | D | 句首大写 + 狗名 Max 是专有名词大写；dog 是普通名词不大写。 |
| Q17 | A | 只有 A 是疑问句。 |
| Q18 | B | 列举用逗号，and 前不加（澳洲惯例）。 |
| Q19 | C | 撇号放在省略字母 o 的位置：don't。 |
| Q20 | B | It's = It is。Its（无撇号）是"它的"。 |
| Q21 | B | 一个男孩 → boy's（撇号在 s 前）。 |
| Q22 | B | 引号包住说的话，逗号在引号内，said Mum 在外。 |
| Q23 | C | 城市名和月份都要大写。 |
| Q24 | B | 复数直接加 s，不加撇号！cats 不是 cat's。 |
| Q25 | B | "小心！"是警告，用感叹号。 |

### Part 3 — Spelling
| 题号 | 答案 | 解析 |
|---|---|---|
| Q26 | chased | 去 e 加 ed 的反向：chase→chased（一个 s 音）。 |
| Q27 | baby → babies（句子应为 two baby brothers 或 two babies；此处考 babies） | 辅音+y → 变 i 加 es。 |
| Q28 | stopped | 短元音+单辅音 → 双写 p。 |
| Q29 | friend | 高频易错：i 在 e 前。口诀：fri-END——朋友到最后（end）。 |
| Q30 | off | of（…的）vs off（离开/掉落）。 |
| Q31 | because | 口诀：**B**ig **E**lephants **C**an **A**lways **U**nderstand **S**mall **E**lephants。 |
| Q32 | carried | 辅音+y → 变 i 加 ed。 |
| Q33 | foxes | x 结尾加 es。 |
| Q34 | thought | ought 家族：thought, brought, bought。 |
| Q35 | school | ch 发 /k/ 音：school, Christmas, echo。 |
| Q36 | there | 表地点。 |
| Q37 | They're | = They are。 |
| Q38 | too | "太多" → too。 |
| Q39 | hear | 用耳朵听（hear 里有 ear！）。 |
| Q40 | know | "知道"。 |
