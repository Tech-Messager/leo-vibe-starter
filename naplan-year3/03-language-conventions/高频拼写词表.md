# 高频拼写词表（Year 3 备考专用）

> 共 200 词，按难度分 4 级，每级 50 词。每周 10 个（周一学 → 周三复习 → 周五听写），错词滚入下周。
> ★ 标记 = NAPLAN 特别爱考的易错词。

## Level 3 — 规则应用（50 词，考拼写规则）

**双写规则**（短元音+单辅音 → 双写加 ing/ed）：
running ★ / stopped ★ / hopping / swimming / clapped / dropped ★ / planned / shopping / hottest / biggest

**y 变 i 规则**：
babies ★ / stories ★ / parties ★ / cities / families ★ / carried ★ / cried / tried / happier / funniest

**去 e 加 ing**：
making / riding / coming ★ / having ★ / writing ★ / hoping / smiling / taking / giving / shining

**es 复数**（s/x/ch/sh 结尾）：
boxes / foxes / buses ★ / brushes / beaches / lunches / wishes / dishes / classes / dresses

**f 变 v**：
leaves ★ / wolves / knives / shelves / lives / halves ★ / loaves / scarves / thieves / calves

**易错点提醒**：writing（一个 t！writing≠written）、coming（不是 comming）、buses（一个 s 加 es）。

## Level 4 — 挑战级（50 词，Strong→Exceeding）

**同音词组 ★★（必考）**：
there–their–they're / to–too–two / your–you're / its–it's / hear–here / where–wear / know–no / right–write / one–won / sea–see

**不发音字母**：
knee / knife / knock / write / wrong / lamb / climb / island ★ / hour ★ / half

**难拼常用词**：
straight ★ / enough ★ / through ★ / laughed ★ / clothes ★ / once ★ / answer ★ / question / picture / minute ★ / together / tomorrow ★ / yesterday / holiday / birthday / surprise ★ / interesting ★ / important / remember | outside

**易错点提醒**：
- enough / through / laughed —— ough/augh 家族要专门练
- tomorrow（一个 m 两个 r）、surprise（sur-prise，第一个 r 别丢）
- interesting（in-ter-est-ing 四段记）

## 20 周听写计划

| 周次 | 内容 | 周次 | 内容 |
|---|---|---|---|
| 1–5 | Level 1（每周10词） | 11–15 | Level 3（每周10词） |

- 每周五听写：本周 10 词 + 上周错词。
- 全部完成后，用各辑练习题和模拟卷里的"找错词"题型做综合检验。
- **听写方法**：念单词 → 念例句 → 再念单词。这正是 NAPLAN 在线拼写题的形式。

## 记忆技巧工具箱

1. **口诀法**：because = **B**ig **E**lephants **C**an **A**lways **U**nderstand **S**mall **E**lephants
2. **藏词法**：h**ear**（听里面有耳朵）、fri**end**（朋友到最后）、is**land**（岛上有陆地 land）
3. **音节拆分**：re-mem-ber, to-mor-row, in-ter-est-ing
4. **彩虹写法**：难词用三种颜色各写一遍（视觉记忆）
5. **Look-Say-Cover-Write-Check**：看→读→盖住→写→对照，澳洲学校标准五步法
