## 答案与解析

### Part 1 — Number and Algebra
| 题号 | 答案 | 解析 |
|---|---|---|
| Q1 | C | 6 在百位 → 600。位值题必考。 |
| Q2 | B | 四位数 > 三位数；1 020 > 1 002（十位 2>0）。 |
| Q3 | B | 位值组合：453。注意 A 的干扰（多个0）。 |
| Q4 | B | 38+25：38+2=40，40+23=63。 |
| Q5 | B | 个位 5+8=13 进位。 |
| Q6 | C | 70−42：70−40=30，30−2=28。 |
| Q7 | B | 52−17=35（"left" → 减法）。 |
| Q8 | C | 逆运算：63−27=36。 |
| Q9 | B | 5×4=20。 |
| Q10 | A | 3×6 = 3 组 6 = 6+6+6。 |
| Q11 | C | 4×5=20（"each" → 乘法）。 |
| Q12 | B | 15÷3=5（"shared equally" → 除法）。 |
| Q13 | B | 18÷2=9。 |
| Q14 | C | 4 等份中的 1 份 = ¼。 |
| Q15 | A | 12÷4=3。 |
| Q16 | B | $5−$3.20：3.20→4.00 是 80c，4.00→5.00 是 $1 → $1.80。 |
| Q17 | B | 50+50+50=150c=$1.50。A=140c，C=$2.50，D=80c。 |
| Q18 | B | 每次 +4 → 20。 |

### Part 2 — Measurement and Geometry
| 题号 | 答案 | 解析 |
|---|---|---|
| Q19 | B | 教室长度用米。kg 和 L 根本不是长度单位（先排除）。 |
| Q20 | B | 1 m = 100 cm。 |
| Q21 | C | 12−3=9。不从 0 量的尺子是经典陷阱。 |
| Q22 | B | 一袋糖 ≈ 1 kg。培养"量感"。 |
| Q23 | C | 分针指 6 = 30 分 → half past 7。 |
| Q24 | B | quarter to nine = 差一刻到九点 = 8:45。 |
| Q25 | B | 2:30 + 1h = 3:30，再 +30min = 4:00。 |
| Q26 | B | hex = 6。口诀：hexagon 六边形（x 像交叉的 6）。 |
| Q27 | C | 四边相等+四直角 = 正方形。长方形只有对边相等。 |
| Q28 | B | 正方体 6 个面（骰子）。 |
| Q29 | D | 罐头 = 圆柱。 |
| Q30 | B | 2×4=8 个方格。数格子求面积。 |

### Part 3 — Statistics and Probability
| 题号 | 答案 | 解析 |
|---|---|---|
| Q31 | A | 8 最大。 |
| Q32 | B | 8−3=5（"how many more" → 减法，不是只读一个数）。 |
| Q33 | B | 8+5+7+3=23（"altogether" → 全加）。 |
| Q34 | C | 图例：1星=2本 → 4×2=8。**先看图例**是象形图的核心。 |
| Q35 | B | 7:1，红多 → more likely red。 |
| Q36 | C | 太阳升起 = certain。下雨只是 possible/likely。 |
