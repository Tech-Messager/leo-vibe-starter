## 答案与解析

### Part 1 — Number and Algebra
| 题号 | 答案 | 解析 |
|---|---|---|
| Q1 | C | two thousand **and forty-five** = 2045。B（2450）是经典干扰。 |
| Q2 | A | 3495+10=3505（十位 9 进位）。 |
| Q3 | D | 687 的十位是 8≥5 → 进到 700。 |
| Q4 | C | 156+244=400（个位 6+4 进位，十位 5+4+1 进位）。 |
| Q5 | A | 500−263=237（连续借位，易错）。 |
| Q6 | B | 124+98：124+100−2=222。 |
| Q7 | A | 两步：27+18=45；60−45=15。 |
| Q8 | B | 6×3=18。 |
| Q9 | B | 9×5=45。 |
| Q10 | C | 24÷3=8（想 3×8=24）。 |
| Q11 | C | 4×$5=$20。 |
| Q12 | B | 两步：3×10=30；30−6=24。 |
| Q13 | A | 8 等份中 3 份 → ⅜。 |
| Q14 | B | 30÷2=15。 |
| Q15 | A | 同一块披萨，½ > ¼。分母越大每份越小——重要概念！ |
| Q16 | B | $2.35+50c=$2.85。 |
| Q17 | B | 85c+$1.10=$1.95。 |
| Q18 | C | 3→6→12→24→48 每次×2（doubling）。 |

### 批改重点
第2辑的分水岭是**两步应用题**（Q7、Q12、Q17、Q20）和**图例象形图**（Q31–33）。这几题错了不要紧，说明思路还停在"一步"，平时多练"先算什么、再算什么"的口头拆题。
