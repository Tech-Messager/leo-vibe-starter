| 编号 | 错因 | 对策 |
|---|------|------|
| ① | 题目没读懂/漏看关键词 | 圈出数字和 NOT/each/altogether 再作答 |
| ② | 两步题只算了一步 | 写下"先算…再算…"再动笔 |
| ③ | 知识点不会 | 回对应《知识点.md》小节重学 |
| ④ | 计算粗心 | 做完用 5 秒"合理性检查" |
| ⑤ | 单位/图例没看 | 图表题先看图例，测量题先看单位 |

## Part 2 — 考前一页纸速查（每科一张）

### 📘 Reading 速查卡
1. 先通读文章 1–2 分钟，再做题；**每题回原文找证据**。
2. 作者意图三选一：故事=entertain，知识=inform，观点=persuade。
3. 推断口诀：**文中线索 + 常识 = 答案**（文章不直说，但一定有暗示）。
4. 主旨题：标题+首段+尾段；选"整篇"不选"细节"。
5. 小心 NOT / EXCEPT / MOST；小心"文中出现过但答非所问"的干扰项。
6. 不会就排除两个再选，**不留空**。

### ✏️ Writing 速查卡
- **时间**：5 构思 → 30 写 → 5 检查（检查专抓：大写、句号、漏词）。
- **Narrative**：开头(谁/哪/何时) → 问题! → 解决+感受。第一句用声音/对话/动作。情绪用身体写（heart pounded），别直说。
- **Persuasive**：观点 → Firstly → Secondly → Finally → 重申观点。至少 2 个技巧：提问/三词排比/strongly believe/呼吁读者。
- 升级词至少 3 个：enormous, whispered, terrified, delighted, dashed...
- 禁忌：不写 "it was all a dream"；议论文立场从头到尾不许变。

### 🔤 Conventions 速查卡
1. 大写：句首、人名地名、月份星期、单独的 I。
2. 撇号两用途：缩写(don't=do not) & 所有格(the girl's hat)；**复数不加撇号**(two dogs)；**its**=它的，**it's**=it is。
3. 不规则过去式高频：went, saw, came, ate, made, took, flew, drew, caught, taught, thought, brought。
4. 主谓一致：单数+s (She plays)；children/mice/sheep 特殊复数；There is+单数 / There are+复数。
5. 拼写规则四板斧：双写(stopped)、去e(making)、y→i(babies/cried)、es(boxes/buses)。
6. 同音词：there那里/their他们的/they're=they are；too太/to到/two二；hear听(有ear)/here这里。

### 🔢 Numeracy 速查卡
1. 位值：3472 里的 4 = 400（看它站在哪一位）。
2. 信号词：altogether/total=加，left/more than(比较)=减，each/groups of=乘，shared equally=除。
3. 两步题先说"先算…，再算…"。
4. 钱：找零用"数上去"法（$3.20→$4 是 80c，$4→$5 是 $1）。
5. 时间：分针指 3=15分(quarter past)，指 6=30分(half past)，指 9=45分(quarter to 下一个钟点)。
6. 图表：**先看图例**（1个符号=几个？）；"how many more"=相减。
7. 立体图形：cube 面6棱12顶点8；罐头=cylinder；球=sphere。
8. 单位：1m=100cm，1kg=1000g，1L=1000mL；读尺子不从0起要相减。
9. 不会的题：估算+排除，选一个，**不留空**，做好标记继续走。

## Part 3 — 四科自评复习清单（考前逐项打勾）

### Reading
- [ ] 能说出五种文体和各自特征
- [ ] 推断题正确率 ≥ 7/10
- [ ] 知道 fact 和 opinion 的区别
- [ ] 认识 however/firstly/finally 等连接词的作用

### Writing
- [ ] Narrative 三段结构能背出来
- [ ] Persuasive 汉堡结构能背出来
- [ ] 能写出 3 种不同的 sizzling start
- [ ] 40 分钟内能完成一篇并检查

### Conventions
- [ ] 词表 Level 1–2 听写全对
- [ ] 词表 Level 3 规则词正确率 ≥ 9/10
- [ ] its/it's、there/their/they're 从不搞混
- [ ] 不规则过去式 20 个脱口而出

### Numeracy
- [ ] ×2 ×3 ×5 ×10 口诀 3 分钟 30 题全对
- [ ] 两步应用题正确率 ≥ 7/10
- [ ] 钟面读时间（含 quarter to/past）不出错
- [ ] 面/棱/顶点、单位换算表背熟
